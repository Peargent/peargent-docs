# Peargent Documentation

This repository contains the source code for the official documentation of [Peargent](https://github.com/Peargent/peargent).

**Peargent** is a modern, simple, and powerful Python framework for building intelligent AI agents with production-grade features. It offers a clean, intuitive API for creating conversational agents that can use tools, maintain memory, collaborate with other agents, and scale reliably into production.

## Features

- **Built with Next.js & Fumadocs**: Fast, accessible, and easy to maintain documentation site.
- **MDX Content**: Documentation is written in MDX, allowing for interactive components.
- **Tailwind CSS**: Styled with Tailwind for a modern look.

## Getting Started

### Prerequisites

- Node.js 18+
- npm, pnpm, or yarn

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/Peargent/peargent-docs.git
cd peargent-docs
npm install
```

### Running Locally

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `content/`: Contains the actual documentation MDX files.
- `src/app/`: Next.js app directory (pages, layouts, components).
- `public/`: Static assets.
